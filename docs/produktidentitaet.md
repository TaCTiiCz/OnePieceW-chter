# Produktidentität der Sonderprodukte

Geklärt anhand der **offiziellen englischen Seite** `en.onepiece-cardgame.com` (abgerufen 06.10.2026).

## Premium Card Collection -29th Anniversary Edition-

- Offizielle Seite: <https://en.onepiece-cardgame.com/products/cardcollection29th.html>
- UVP: **USD 10,00**
- Inhalt: 2 Kartenarten, insgesamt 8 Karten (Karte **P-159**):
  - Normal-Version (gleiche Beilage wie Weekly Shonen Jump Ausgabe 33) ×4
  - Premium-Version (besondere Kartenveredelung) ×4
- Vertrieb: Vorbestellung über **Premium Bandai** – auf der offiziellen Seite verlinkt sind nur die Regionen
  **US, AU, NZ**. Eine EU-Region war nicht verlinkt. In Europa ist sie daher vermutlich nur über Importeure erhältlich.
- Nicht verwechseln mit: Premium Card Collection *-25th Edition-*, *Best Selection Vol.x*, *Live Action Edition*,
  *6 assort*, *Ace & Sabo & Luffy* – diese werden vom Wächter ausdrücklich ausgeschlossen.
- Hinweis: Da die Normal-Version eine Beilage der japanischen Weekly Shonen Jump ist, kann es japanische Fassungen
  geben. Der Wächter verlangt deshalb eine **englische** Sprachangabe im Titel.

## „2nd Anniversary LIMITED COLLECTION“ (Englisch)

**Ergebnis der Klärung:** Auf der offiziellen englischen Seite wurde **kein** Produkt mit dem Namen
„2nd Anniversary LIMITED COLLECTION“ gefunden. Das einzige offizielle englische Produkt zum 2. Jubiläum ist:

### ONE PIECE CARD GAME English Version 2nd Anniversary Set

- Offizielle Seite: <https://en.onepiece-cardgame.com/products/other/2nd_anniversary_set.php>
- UVP: **USD 90,00**, Lieferung **Juni 2025**, Vertrieb über **Premium Bandai**
  (<https://p-bandai.com/us/item/N2773432001001>)
- Inhalt: Playmat ×1, Leader Card ×4, Character Card ×4, DON!! Card ×10, Storage Box ×1
  (Motiv: „New Four Emperors“)

Wiederverkäufer bezeichnen dieses Set teils als „Limited Collection“. Ob jemand mit „2nd Anniversary LIMITED
COLLECTION“ genau dieses Set meint, ist **nicht belegt**. Deshalb:

- Angebote mit dem offiziellen Namen („English Version 2nd Anniversary Set“) → **sicherer Treffer**.
- Angebote mit „2nd Anniversary … Limited Collection“ → nur **unsicherer Treffer** (kein Kaufalarm).

Ausdrücklich ausgeschlossen (Verwechslungsgefahr):

| Produkt | Warum nicht |
|---|---|
| Japanese 2nd Anniversary Set | japanische Fassung, anderes Produkt |
| 2nd Anniversary Complete Guide (Buch + Karten, JP) | Buch, kein Set |
| BASE SHOP Limited Card Collection vol.1/vol.2 (JP) | japanisches Shop-Produkt, kein Jubiläumsset |
| 25th Anniversary / Premium Card Collection -25th Edition- | 25 Jahre *Manga*, nicht 2 Jahre *Kartenspiel* |
| 1st / 3rd / 4th Anniversary Set | anderes Jubiläum |
| 2nd Anniversary Tournament (Promo-Preise) | Turnierpreise, kein Verkaufsprodukt |
| Special Goods Set – Former Four Emperors | anderes Zubehörset |

**Bitte selbst bestätigen:** Falls du mit „2nd Anniversary LIMITED COLLECTION“ ein anderes Produkt meinst
(z. B. aus einem Händler-Angebot), schick mir den Link. Dann passe ich `config/products.toml` an.
